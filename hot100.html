Go 数组与切片的自定义排序#

Go 可以使用 sort.Slice 对切片原地排序。比较函数返回 true，表示下标 i 的元素应该排在下标 j 的元素前面。比较必须使用严格关系 < 或 >，不能使用 <= 或 >=。

package main

import (
    "fmt"
    "sort"
)

func main() {
    nums := []int{3, 1, 5, 2, 4}

    // 升序
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] < nums[j]
    })
    fmt.Println(nums) // [1 2 3 4 5]

    // 降序
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] > nums[j]
    })
    fmt.Println(nums) // [5 4 3 2 1]
}

固定长度数组要先通过 [:] 取得切片，再交给 sort.Slice：

arr := [5]int{3, 1, 5, 2, 4}

sort.Slice(arr[:], func(i, j int) bool {
    return arr[i] > arr[j]
})

结构体可以依次比较多个字段。下面先按 First 降序，First 相同时再按 Second 降序：

type Pair struct {
    First  int
    Second int
}

pairs := []Pair{
    {First: 2, Second: 5},
    {First: 1, Second: 8},
    {First: 2, Second: 3},
}

sort.Slice(pairs, func(i, j int) bool {
    if pairs[i].First != pairs[j].First {
        return pairs[i].First > pairs[j].First
    }
    return pairs[i].Second > pairs[j].Second
})

C++ 数组与 vector 的自定义排序#

std::sort(first, last, comp) 中，如果 comp(a, b) 返回 true，表示 a 应排在 b 前面。因此，普通排序里写 a > b 表示降序。

#include <algorithm>
#include <functional>
#include <iterator>
#include <utility>
#include <vector>
using namespace std;

int nums[] = {3, 1, 5, 2, 4};

// 原生数组升序
sort(begin(nums), end(nums));

// 原生数组降序
sort(begin(nums), end(nums), greater<int>());

vector<int> values = {3, 1, 5, 2, 4};

// vector 自定义降序
sort(values.begin(), values.end(), [](int a, int b) {
    return a > b;
});

pair<int, int> 先按 first 降序，值相同时按 second 降序：

vector<pair<int, int>> pairs = {
    {2, 5}, {1, 8}, {2, 3}
};

sort(pairs.begin(), pairs.end(),
     [](const pair<int, int>& a, const pair<int, int>& b) {
         if (a.first != b.first) {
             return a.first > b.first;
         }
         return a.second > b.second;
     });

先按 second 降序，值相同时按 first 降序：

sort(pairs.begin(), pairs.end(),
     [](const pair<int, int>& a, const pair<int, int>& b) {
         if (a.second != b.second) {
             return a.second > b.second;
         }
         return a.first > b.first;
     });

pair 默认按字典序比较，所以 greater<pair<int, int>>() 也可以实现“先按 first 降序，first 相同时按 second 降序”：

sort(pairs.begin(), pairs.end(), greater<pair<int, int>>());

C++ priority_queue 的自定义排序#

堆不是把所有元素完整排好序，而是始终保证 top() 是当前优先级最高的元素。连续执行 top() 和 pop()，才能依次取出元素。

#include <functional>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

// 大顶堆：最大值先出
priority_queue<int> maxHeap;

// 小顶堆：最小值先出
priority_queue<int, vector<int>, greater<int>> minHeap;

priority_queue 的比较器与 sort 看起来是反的：如果 comp(a, b) 返回 true，表示 a 的优先级比 b 低，a 应该下沉。因此，要让较大的值先出堆，比较器里使用 <。

对于 pair<int, int>，按 first 降序出堆；first 相同时按 second 降序：

using PII = pair<int, int>;

struct FirstDesc {
    bool operator()(const PII& a, const PII& b) const {
        if (a.first != b.first) {
            return a.first < b.first;
        }
        return a.second < b.second;
    }
};

priority_queue<PII, vector<PII>, FirstDesc> firstHeap;

firstHeap.push({2, 5});
firstHeap.push({1, 8});
firstHeap.push({2, 3});

// 弹出顺序：(2, 5)、(2, 3)、(1, 8)

按 second 降序出堆；second 相同时按 first 降序：

using PII = pair<int, int>;

struct SecondDesc {
    bool operator()(const PII& a, const PII& b) const {
        if (a.second != b.second) {
            return a.second < b.second;
        }
        return a.first < b.first;
    }
};

priority_queue<PII, vector<PII>, SecondDesc> secondHeap;

secondHeap.push({2, 5});
secondHeap.push({1, 8});
secondHeap.push({3, 5});

// 弹出顺序：(1, 8)、(3, 5)、(2, 5)

如果就是“按 first 降序，first 相同时按 second 降序”，可以直接使用默认大顶堆：

priority_queue<pair<int, int>> heap;

最简记忆：普通 sort 降序通常写 a > b；priority_queue 要让较大的元素先出，比较器通常写 a < b。

1. 两数之和 - Easy#

题目：给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 *target* 的那 两个 整数，并返回它们的数组下标。

思路：这道题本身如果通过暴力遍历的话也是很容易解决的，时间复杂度在 O($n^2$)；由于哈希查找的时间复杂度为 O(1)，所以可以利用哈希容器 map 降低时间复杂度；使用哈希表存储， key存储数组值、value存储下标；遍历数组 nums，i 为当前下标，每个值都判断map中是否存在 key == target-nums[i] 的值；如果存在，则找到了两个值，如果不存在，则将当前的 (nums[i] , i) 存入 map 中，继续遍历直到找到为止。

func twoSum(nums []int, target int) []int {
    mp := map[int]int{} 
    for i, num := range nums {
        if p, ok := mp[target-num]; ok {
            return []int{p, i}
        }
        mp[num] = i
    }
    return nil
}

  1. golang里面判断map里面有没有某一个键值对应该用：if p, ok := mp[key]; ok {}

49. 字母异位词 - Mid#

题目：给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

字母异位词 是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。

思路：本质上题意是把同一类词进行分组，所以可以使用Map（key: 同一类词的相同唯一特征, value: 字母异位词的集合）。由于互为字母异位词的两个字符串里所包含的字母相同，因此对两个字符串分别进行排序之后得到的字符串一定是相同的，故可以将排序之后的字符串作为哈希表的键，而原来的字符串都加入到Value(集合)中。

func groupAnagrams(strs []string) [][]string {
    mp := map[string][]string{} 
    for _, str := range strs {
        s := []byte(str)
        sort.Slice(s, func (i, j int) bool {
            return s[i] < s[j]
        })
        sortedStr := string(s) 
        mp[sortedStr] = append(mp[sortedStr], str)
    }
    ans := [][]string{} 
    for _, strings := range mp {
        ans = append(ans, strings)
    }
    return ans
}

注意：

  1. 对字符 slice s 做升序排序应该用：sort.Slice(s, func(i, j int) bool { return s[i] < s[j] })。比较函数必须使用严格关系，不能使用 <=。

128. 最长连续序列#

题目：给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为 O(n)的算法解决此问题。

思路 - 寻找以每个数字作为连续序列起点的对应序列长度：

  • 先将所有数字存入哈希表，用于快速判断某个数字是否存在；
  • 然后遍历哈希表中的每个数字num：
  • 如果 num-1 存在，说明这个数字 num 不是某个连续序列的起点，跳过；
  • 如果 num-1 不存在，则从当前数字 num 开始向后查找，统计连续递增序列的长度；
  • 记录并更新最大长度。
func longestConsecutive(nums []int) int {
    numSet := map[int]bool{}
    for _, num := range nums {
        numSet[num] = true 
    }
    longestStreak := 0 
    for num := range numSet {
        if !numSet[num-1] {
            currentNum := num
            currentStreak := 1
            for numSet[currentNum+1] {
                currentNum++
                currentStreak++
            }
            if currentStreak >= longestStreak {
                longestStreak = currentStreak
            }
        } 
    }
    return longestStreak
}

283. 移动零 - Easy#

题目：给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意 ，必须在不复制数组的情况下原地对数组进行操作。

思路：一次遍历，只要把左侧的零和右侧的非零数字进行交换即可。

定义两个指针，slow=0，fast=0。

  1. 如果 nums[fast]==0，fast指针就往右移一步。
  2. 如果 nums[fast]≠0，就交换 nums[fast] 和 nums[slow] 的值，然后 fast指针 和 slow指针都往右移一步。
func moveZeroes(nums []int)  {
    slow := 0
    for fast:=0; fast < len(nums); fast++ {
        if nums[fast] != 0 {
            nums[slow], nums[fast] = nums[fast], nums[slow] 
            slow++
        } 
    }
}

11. 盛最多水的容器 - Mid#

题目：给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

思路：

题意为：求围成的最大面积，面积等于宽x高，宽为j-i，高为 min(height[i], height[j])，即给定数组 height，任选两个下标 i 和 j，求 (j-i) * min(height[i], height[j]) 的最大值解题思路为双指针，左指针从最左侧开始向右检索，右指针从最右侧开始向左检索，但每次只移动高度较小的那个指针，遍历过程中计算出当前围成的面积，并且记录最大面积。

为什么每次只移动高度较小的指针？这就和水桶的盛水量是由最矮的阀决定的道理一致。

  • 如果 height[i] < height[j]，那么在 (i, i+1), (i, i+2), …, (i, j-1) 区间的面积都小于 (i, j) 区间的面积。因为固定了 i ，因此中间围成的面积，其 高 最高不超过 i，其 宽 最宽也不超过 j-i。
func maxArea(height []int) int {
    i, j := 0, len(height)-1 
    ans := 0 
    for i < j {
        ans = max(ans, min(height[i], height[j])*(j-i)) 
        if height[i] >= height[j] {
            j--
        } else {
            i++
        }
    }
    return ans
}

15. 三数之和 - Mid#

题目：给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

思路：

  • 固定一个数，将三数之和转换为两数之和；
  • 数组排序，使用双指针求解两数之和；
  • 移动指针过程中对组合去重；

具体解释：

先排序，固定第一个数 nums[i], 则目标值变为 0 - nums[i]；

再使用双指针 j 和 k 求解两数之和 nums[j] + nums[k] == 0 - nums[i]；

  • 此处的 j = i + 1，k = nums.length - 1；
  • 若 nums[j] + nums[k] > 0 - nums[i]，则应该令两数之和减小，即 k—；
  • 若 nums[j] + nums[k] < 0 - nums[i]，则应该令两数之和增大，即 k++；
  • 若 nums[j] + nums[k] == 0 - nums[i]，则这三个数就是满足条件的，应该加入结果集；
  • 加入结果集后，需要对 第二个数的后面 和 第三个数的前面 进行去重。先记录当前指针的值，然后一直移动指针，直到数值不相等为止。
  • 接着 对第一个数进行去重。

然后 循环下一个 nums[i] ，重复上述过程。

func threeSum(nums []int) [][]int {
    res := [][]int{} 
    sort.Ints(nums)
    for i := 0; i < len(nums)-2; i++ {
        if nums[i] > 0 {
            break
        } 
        target := 0 - nums[i] 
        j, k := i+1, len(nums)-1 
        for j < k {
            if nums[j] + nums[k] < target {
                j++
            } else if nums[j] + nums[k] > target {
                k--
            } else {
                res = append(res, []int{nums[i], nums[j], nums[k]}) 
                second, third := nums[j], nums[k] 
                for j < k && nums[j] == second {
                    j++
                }
                for k > j && nums[k] == third {
                    k--
                }
            }
        }
        first := nums[i] 
        for i < len(nums)-2 && nums[i+1] == first {
            i++
        }
    }
    return res
}

注意：

  1. 去重是为了不让下一轮循环再用同一个数字，在给 第一个数字 去重的时候，判断的是 nums[i+1] ：只跳过未来重复的，不碰已经用过的当前 i ！
  2. j 和 k 可以直接用 nums[j] 和 nums[k]，其实也是为了从当前位置挪开，进入下一个可能获取的新解法的位置！

42. 接雨水 - Hard#

题目：给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

!image.png

思路：

把上图切分为 宽度为1、高度不定 的柱子，分别计算每个柱子可接的雨水 = 宽（即1）* 高度不定，而每个柱子可接的雨水的高度 是由什么决定的呢？

是由该柱子的 左边区间的最高柱子 和 右边区间的最高柱子 以及 当前柱子的高度 三者共同决定的。即每个柱子可接的雨水的高度 = Min（左边区间的最高柱子，右边区间的最高柱子）- 当前柱子的高度。

因此先统计 每一个柱子 的 左边区间 和 右边区间 的 最高柱子的高度。

用 这两个高度的最小值 减去 当前柱子高度 再乘x以 宽度（即1） = 当前这个柱子可接的雨水。

  • 如何统计 每一个柱子 的 左边区间 和 右边区间 的 最高柱子的高度。
  • 定义两个数组，leftMax[n] 前缀最大值 和 rightMax[n] 后缀最大值。
  • 例如 leftMax[2] 表示从 0-2 中最高柱子的高度，rightMax[5] 表示从5-11中最高柱子的高度。
  • 则 leftMax[i] = Math.max(leftMax[i-1], height[i])；
  • rightMax[i] = Math.max(rightMax[i+1], height[i]);
func trap(height []int) int {
    n := len(height)
    leftMax, rightMax := make([]int, n), make([]int, n)

    leftMax[0] = height[0] 
    for i:=1; i < n; i++ {
        leftMax[i] = max(leftMax[i-1], height[i]) 
    }

    rightMax[n-1] = height[n-1] 
    for i:=n-2; i >= 0; i-- {
        rightMax[i] = max(rightMax[i+1], height[i]) 
    }

    rainSum := 0
    for i:=0; i<n; i++ {
        rainSum += max(min(leftMax[i], rightMax[i]) - height[i], 0)
    }

    return rainSum
}

3. 无重复字符的最长子串 - Mid#

题目：给定一个字符串 s ，请你找出其中不含有重复字符的 最长子串 的长度。

思路：

基于 滑动窗口 的方式来解此题。所谓滑动窗口，其实就是由两个索引维护一个区间，满足一定条件时会动态地去调整这个区间。这里的两个索引决定了滑动窗口的起点和终点，始终保持滑动窗口中的元素是不重复的，这题就变成了找到包含非重复元素的最长窗口。

  • 双指针指向不含重复字符的连续字串的头和尾：定义 right 和 left 指针，初始值为 0；
  • 用集合存储子串中的元素：Set<Character> set = newHashSet<>();

具体流程：

  • 当前窗口为 (0,0)，当前 right 指向元素在当前窗口中不重复：
  • 因此 right 指向元素加入集合、当前窗口长度++、更新无重复字符的最长子串的长度、right 指针右移、扩大窗口；
  • 当窗口中出现重复的元素时：
  • 因此，集合移除 left 指向元素、当前窗口长度—、left指针右移，缩小窗口，期望使得窗口内无重复（注意这里只是期望，并不一定移除了 left 指向元素就会是的窗口内无重复元素，但是没关系，只要继续循环，会重复走入该分支情况，终将会是的窗口中无重复元素）
func lengthOfLongestSubstring(s string) int {
    maxL, left, right, curLen := 0, 0, 0, 0 
    wind := map[byte]bool{} 
    for right < len(s) {
        if !wind[s[right]] {
            wind[s[right]] = true 
            curLen++
            maxL= max(maxL, curLen) 
            right++
        } else {
            wind[s[left]] = false 
            curLen--
            left++
        }
    }
    return maxL
}

注意：

  1. 如果用map且值类型是int，会把不存在的key对应的value默认为0；

438. 找到字符串中所有字母异位词 - Mid#

题目：给定两个字符串 s 和 p，找到 s中所有 p的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

思路：

因为字符串 p 的长度是固定的，那么就需要在字符串 s 中找到长度相同的子串。 即需要遍历字符串 s 中所有长度与 p 相同的子串，此时就可以使用滑动窗口来解决。

定义两个索引 left 和 right：

  • 保证字符串 s 中由区间 [left, right] 组成窗口的长度 始终等于字符串 p 的长度；
  • 令这个窗口向后不断滑动，不断检查当前窗口组成的子串字符是否是字符串 p 的异位词；

如何快速地判断当前窗口组成的子串字符，是否就是字符串 p 的异位词？

  • 方案一：把当前窗口组成的子串排序，以及字符串 p 内部也排序，如果两个字符串排序后相同，则说明当前窗口的子串就是字符串 p 的异位词。但需要排序，整体时间复杂度就会很高。
  • 方案二：可以引入 两个数组 （只需要数组的长度为 26，因为题目明确了 s 和 p 只包含小写字母），一个用于记录当前窗口中所有字符的频次，另一个用于记录字符串 p 中所有字符的频次。那么判断当前窗口是否是字符串 p 的异位词，就只需要判断这 两个数组 是否完全相同。
func findAnagrams(s string, p string) []int {
    res := []int{}
    if len(p) > len(s) {
        return res
    }

    winSize := len(p)
    // pSlice := make([]int, 26) // 切片只能和nil比较 存成数组！
    var pSlice [26]int
    for i:=0; i < winSize; i++ {
        pSlice[p[i]-'a']++
    }

    var tmp [26]int
    count := 0
    for i:=0; i < len(s); i++ {
        tmp[s[i]-'a']++
        count++ 

        if i >= winSize {
            tmp[s[i-winSize]-'a']--
            count--
        }

        if i >= winSize-1 &&  tmp == pSlice {
            res = append(res, i-winSize+1)
        }
    }
    return res
}

560. 和为 K 的子数组#

题目：给你一个整数数组 nums 和一个整数 k ，请你统计并返回 *该数组中和为 k的子数组的个数* 。

子数组是数组中元素的连续非空序列。

思路：

前缀和的概念

  • 首先，我们使用一个叫做“前缀和”的概念。对于数组中的任何位置 j ，前缀和 preSum[j] 是数组中从第一个元素到第 j 个元素的总和。
  • 这意味着如果你想知道从元素 i+1 到 j 的子数组的和，你可以用 preSum[j] - preSum[i] 来计算。

使用 Map 来存储前缀和

  • 在代码中，我们用一个 Map（哈希表）来存储 每个前缀和出现的次数。
  • 这是为了快速检查某个特定的前缀和是否已经存在，以及它出现了多少次。

核心逻辑解析

  • 当我们在数组中向前移动时，我们逐步增加 preSum（当前的累计和）。
  • 对于每个新的前缀和 preSum 值，我们检查 preSum - k 是否在 Map 中。
  • preSum - k 的意义：这个检查的意义在于，如果 preSum - k 存在于 Map 中，说明当前在某个点的累积和是 preSum - k。由于当前的累计和是 preSum，这意味着从那个点到当前点的子数组之和恰好是 k（因为preSum - （preSum-k）=k）。
  • 如何使用这个信息：如果 preSum-k 在 Map 中，那么 preSum-k出现的次数表示从不同的起始点到当前点的子数组和为 k 的不同情况。这是因为每一个 preSum-k 都对应一个起点，使得从那个起点到当前点的子数组和为k。
  • 因此，每当我们找到一个 preSum-k 存在于 Map 中时，我们就把它的计数（即之前这种情况发生的次数）加到 count 上，因为这表示我们又找到了相应数量的以当前元素结束的子数组，其和为 k 。

总结：

  • 前缀和+哈希表：遍历数组时计算前缀和，将前缀和作为 key 以及出现的次数作为 value 存进哈希表。对于遍历到下标 i 时，只需要知道在之前的前缀和值为 preSum[i] - target 出现的次数即可，然后把次数相加。
func subarraySum(nums []int, k int) int {
    count, preSum := 0, 0 
    mp := map[int]int{}
    mp[0] = 1
    for _, num := range nums {
        preSum += num 
        if _, ok := mp[preSum-k]; ok {
            count += mp[preSum-k]
        }

        mp[preSum]++
    }
    return count
}

思路：

  • 在数组中移动一个固定大小的滑动窗口，然后维护一个大顶堆（堆顶为最大）；
  • 优先队列里存的是 (nums[i], i) ，用 nums[i] 来对整数对进行排序；
  • 每遍历一个数的时候，都把它 emplace 进优先队列，然后开始取堆顶；
  • 对堆顶的对应索引 topIdx 值做判断：如果 curIdx - topIdx ≥ k ，那就说明这个堆顶的元素实际上已经在滑动窗口左边界的外侧了，应予以 pop！
  • 把所有不在滑动窗口内（但是相对比较大）的元素都从优先队列里pop掉之后，堆顶就是当前滑动窗口范围内的最大值！
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        priority_queue<pair<int, int>> q; 
        int n = nums.size(); 
        for (int i=0; i < k; i++) {
            q.emplace(nums[i], i);
        }
        vector<int> ans = {q.top().first};
        for (int i=k; i < n; i++) {
            q.emplace(nums[i], i);
            while (q.top().second <= i-k) {
                q.pop();
            }
            ans.push_back(q.top().first);
        }
        return ans;
    }
};

76. 最小覆盖子串 - Hard#

题目：给你一个字符串 s 、一个字符串 t 。返回 s 中涵盖 t 所有字符的最小子串。如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串 "" 。

注意：

  • 对于 t 中重复字符，我们寻找的子字符串中该字符数量必须不少于 t 中该字符数量。
  • 如果 s 中存在这样的子串，我们保证它是唯一的答案。

思路：本题是经典的滑动窗口类型，解决这类问题的关键是窗口左右边界的滑动策略。

定义

  • 哈希表 targetMap<byte, int> 保存字符串 t 中字符的频率，哈希表 windowMap<byte, int> 保存滑动窗口中字符出现的次数。
  • left 保存窗口的左边界，right 保存窗口的右边界；
  • resStart 保存最小子串的起始位置，resLen 保存最小子串的长度。

在字符串 s 上的窗口滑动策略如下：

  1. targetMap 中的元素不全在 windowMap 中，right 向右滑动，并更新 windowMap[s[right]]++，直到 targetMap 中的元素全在 windowMap 中；
  2. targetMap 中的元素全在 windowMap 中，left 向右滑动，并更新 windowMap[s[left]]--、最小覆盖子串的起始位置 resStart 和 最小覆盖子串的长度 resLen，直到 targetMap 中的元素不全在 windowMap 中。

效果：

根据上面的滑动策略 我们可以获得 以 s 任意位置为左边界（枚举左边界）的所有候选窗口，只需要把其中最短的一个窗口返回即可。

如何判断 targetMap 中的元素是否全在 windowMap 中，即如何判断当前窗口的字符串已经覆盖了目标字符串？

  • 方案一：可以采用遍历 targetMap 对其中的元素一个个去 windowMap 中比较。
  • 方案二：借用一个整型变量 tInWindow 在窗口滑动的过程中就对窗口中字符情况进行统计，大大节省了每次判断都要去遍历 hash 表的时间。
func minWindow(s string, t string) string {
    targetMap := map[byte]int{} 
    windowMap := map[byte]int{} 
    resStart, resLen := 0, math.MaxInt32

    for i := 0; i < len(t); i++ {
        targetMap[t[i]]++
    }

    checkCovered := func() bool {
        for ch, count := range targetMap {
            if windowMap[ch] < count {
                return false
            }
        }
        return true
    }

    for left, right := 0, 0; right < len(s); right++  {
        if targetMap[s[right]] > 0 {
            windowMap[s[right]]++ 
        }
        for checkCovered() && left <= right {
            if resLen > right-left+1 {
                resLen = right-left+1 
                resStart = left
            }
            if _, ok := targetMap[s[left]]; ok {
                windowMap[s[left]]--
            }
            left++ 
        }
    }

    if resLen == math.MaxInt32 {
        return ""
    }

    return s[resStart:resStart+resLen]
}

注意：

  1. 一定程度上的剪枝：在对windowMap中的值进行操作的时候，可以先检查当前操作的这个字母是否存在于 t 字符串中；如果不存在，可以不对windowMap做操作，这样既可以节省时间也可以节省空间。

215. 数组中的第 K 个最大元素 - Mid#

题目：给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

思路：TopK类题都可以用堆解题，那么要用小顶堆还是大顶堆呢？此时就需要根据其特性结合题目选择。根据堆的特性（以及题目要求第k最大值），我们需要小顶堆（只存储k个元素）。

将来最小值不断弹出，而将偏大值留在堆内。

或者这里可以直接巧记，如果题目要求找最大，那么就用小顶堆。如果题目要求找最小，那么就用大顶堆。由于题目要求找到第k个最大的元素，因此这里使用小顶堆。并且记住，堆里我们需要维持只存K个元素。

整体流程：当然我们需要遍历一遍数组，将每一个元素都尝试将其加入堆中。

具体流程：遍历数组

  • 先把当前遍历到的元素 加入堆中，由于堆的特性，会根据大小自动调整顺序，将最小的移到堆顶。
  • 此时判断堆中存储的元素是否超过k个，若超过k个，则把堆顶的元素弹出，这就维持了堆中元素是k个，且注意弹出的是最小值，那么堆内留下的就是偏大的值。
  • 因为数组所有的值都会加入到堆中，并且经过调整和弹出，会把所有小的值弹出。
  • 最终遍历完成后，堆中留下的就是k个最大值，并且堆顶就是我们需要的第k个最大值。
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        if (nums.size() < k) return 0;
        priority_queue<int, vector<int>, greater<int>> pq; 
        for (int i=0; i < nums.size(); i++) {
            pq.emplace(nums[i]); 
        }
        while (pq.size() > k) {
            pq.pop();
        }
        return pq.top();
    }
};

public:
    struct compare {
        bool operator()(pair<int,int>& a, pair<int,int>& b) {
            return a.second > b.second;
        }

            mp[nums[i]]++;

295. 数据流的中位数 - Hard#

题目：中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

  • 例如 arr = [2,3,4] 的中位数是 3 。
  • 例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5 。

实现 MedianFinder 类:

  • MedianFinder() 初始化 MedianFinder 对象。
  • void addNum(int num) 将数据流中的整数 num 添加到数据结构中。
  • double findMedian() 返回到目前为止所有元素的中位数。与实际答案相差 10(-5) 以内的答案将被接受。

思路：这里需要巧思，记住解决方案即可

人为构造一个大顶堆 leftHalf 和 一个小顶堆 rightHalf，且需遵守如下规定。

  • 当数据流元素数量为偶数：规定 leftHalf 和 rightHalf 大小相同，此时动态中位数为两者堆顶元素的平均值。
  • 当数据流元素数量为奇数：规定 leftHalf 比 rightHalf 多一，此时动态中位数为 leftHalf 的堆顶数。
  • 规定 两个堆加起来的数是 完整的数据流从小到大的所有数。

上述是人为规定，而编码需要遵循上述规则。

如何实现：题目中需要实现三个函数：MedianFinder的构造函数，添加元素addNum，取中位数findMedian。

  • 构造函数中，构造大顶堆 (预计存放数据流的左半边元素) 和 小顶堆 (预计存放数据流的右半边元素) 即可。
  • 添加元素addNum函数中，需要分几种情况，假设需要新添加 num。
  • 若双端为空(即两个堆都为空)，直接把当前要加入的元素，加入到 leftHalf 即可。
  • 若插入前，leftHalf 中的数量比 rightHalf 中的数量多 1个。
  • 若 左半边的最大数 leftHalfTop > num，则应将leftHalfTop加到右半边，把 num 加到左半边。
  • 若 左半边的最大数 leftHalfTop <= num，则应将 num 加到右半边。
  • 若插入前，leftHalf 中的数量 == rightHalf 中的数量。
  • 若 leftHalfTop <= num <= rightHalfTop，则应该把 num 加到左半边。
  • 若 leftHalfTop > num ，则应该把 num 加到左半边。
  • 若 rightHalfTop < num，则应该把 rightHalfTop 加到左半边，并且把 num 加到右半边。
  • 取出中位数的findMedian函数中，就简单了。
  • 左半边的数量 大于 右半边的数量，直接返回左半边的堆顶数。
  • 左半边的数量 等于 右半边的数量，返回左右半边堆顶数的平均值。
class MedianFinder {
public:
    priority_queue<int, vector<int>, less<int>> pq_min; 
    priority_queue<int, vector<int>, greater<int>> pq_max;
    
    MedianFinder() {}
    
    void addNum(int num) {
        if (pq_min.empty() || num < pq_min.top()) {
            pq_min.push(num); 

            if (pq_min.size() > pq_max.size()+1) {
                pq_max.push(pq_min.top());
                pq_min.pop();
            }
        } else {
            pq_max.push(num); 

            if (pq_max.size() > pq_min.size()) {
                pq_min.push(pq_max.top());
                pq_max.pop();
            }
        }
    }
    
    double findMedian() {
        if (pq_min.size() > pq_max.size()) {
            return pq_min.top(); 
        } else {
            return (pq_min.top()+pq_max.top())/2.0;
        }
    }
};

注意：

  1. push和empalce：push是把已经造好的数放进去，emplace是直接在堆里造一个数；
  2. 关于各种数据结构里的加数：
  3. 堆、优先队列：pq.push(num);
  4. vector：vec.push_back(num);
  5. 哈希表：mp[key] = value;
  6. 栈、队列：st.push(value); | q.push(value);

    if len(s) % 2 == 1 {
        return false
    } 

    stack := []byte{} 
    match := map[byte]byte{
        '(': ')', '{':'}', '[':']',
    }

    for i:=0; i<len(s); i++ {

        } else {
            if len(stack) == 0 || match[stack[len(stack)-1]] != s[i] {
                return false
            }
            stack = stack[:len(stack)-1]
        }
    }

    return len(stack) == 0
}

155. 最小栈 - Mid#

题目：设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

  • MinStack() 初始化堆栈对象。
  • void push(int val) 将元素val推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

思路：

  • 需要两个栈，主栈用于保存正常push进的元素，一个辅助栈 min_stack，用于存 以及 获取 stack 中最小值。
  • 算法流程：
  • push() 方法： 每当 push() 新值进来时，如果 新值 <= min_stack的栈顶值，则把新值也存入 min_stack，使得 min_stack 的栈顶始终是整个栈 stack 中的最小值；
  • pop() 方法： 若当前要弹出的元素 (是最小值) == min_stack 的栈顶值(即最小值)，那么也要把min_stack的栈顶值弹出，这样可以保证 min_stack 栈顶元素始终是整个栈 stack 中的最小值；
  • getMin()方法： 返回 min_stack 栈顶元素即可；
  • top()方法：返回 stack 栈顶元素即可；
  • min_stack 作用分析：
  • 因为 stack 是可能弹出元素的，所以整个栈的最小值是动态变化的，有可能 最小值由 a 变成 b（因为弹出b） 再变成 a ；因此最小值也需要动态的记录，而 min_stack 专门用于跟踪和存储主栈中的最小值序列，它维护了一个"最小值的历史记录"，使得我们能够在O(1)时间内获取当前栈中的最小元素。
type MinStack struct {
    stack []int
    minStack []int
}

func Constructor() MinStack {
    return MinStack{
        stack: []int{}, 
        minStack: []int{math.MaxInt64}, // 保证minStack一定能取出数
    }
}

func (this *MinStack) Push(val int)  {
    this.stack = append(this.stack, val) 
    if len(this.minStack) == 0 || val <= this.minStack[len(this.minStack)-1] {
        this.minStack = append(this.minStack, val) 
    }
}

func (this *MinStack) Pop()  {
    tmp := this.Top() 
    this.stack = this.stack[:len(this.stack)-1]
    if tmp == this.minStack[len(this.minStack)-1] {
        this.minStack = this.minStack[:len(this.minStack)-1]
    }
}

func (this *MinStack) Top() int {
    return this.stack[len(this.stack)-1]
}

func (this *MinStack) GetMin() int {
    return this.minStack[len(this.minStack)-1]
}

题目：给定一个经过编码的字符串，返回它解码后的字符串。

思路：

需要借助一个栈，遍历字符串的每个字符，遍历过程中

  1. 只要字符不是右括号']'，就将字符压入栈，压栈直到遇到右括号']'
  2. 此时遇到右括号']'，右括号']'就不用入栈了，此时那么只要栈顶的元素不是左括号'['时，就把栈顶元素弹出，即解析最里层[]内的字符串，用temp暂存。一直弹出栈直到遇到'['，

  4. 弹出栈顶的左括号'['

  7. 拼接完成，把新的字符串压入栈中

  • 如果是像有一个整体大括号包裹的"3[a2[c]]",那么最终stack中就只会有一个字符串[accaccacc]

func decodeString(s string) string {
    stack := []string{} 
    for i := 0; i < len(s); i++ {
        if s[i] != ']' {
            stack = append(stack, string(s[i]))
        } else {
            temp := ""
            for len(stack)!=0 && stack[len(stack)-1] != "[" {
                temp = stack[len(stack)-1] + temp 
                stack = stack[:len(stack)-1]
            }
            stack = stack[:len(stack)-1] 

            repeatNumStr := ""
            for len(stack)!=0 && stack[len(stack)-1] >= "0" && stack[len(stack)-1] <= "9" {
                repeatNumStr = stack[len(stack)-1] + repeatNumStr
                stack = stack[:len(stack)-1]
            }

            // 一定要注意string转integer！！！
            repeatNum, _ := strconv.Atoi(repeatNumStr)

            mergeStr := ""
            for i := 0; i < repeatNum; i++ {
                mergeStr += temp
            }
            stack = append(stack, mergeStr)
        }
    }
    finalStr := "" 
    for i := 0; i < len(stack); i++ {
        finalStr += stack[i]
    }
    return finalStr
}

注意：

  1. string 字符串之间本是不可以比较的，但是会按字典序进行一个排序；
  2. byte 转 string 记得 “string()”
  3. string转int要：repeatNum, _ := strconv.Atoi(repeatNumStr)；如果转不了会有报错！

  • 如果 当前遍历的温度 比 栈顶对应的温度 高，那么就找到了栈顶元素的下一个更高温度，计算(当前遍历的温度和栈顶温度的)天数差，且将天数差存入对应位置，最后将栈顶元素弹出栈顶（因为它的下一个更高温度已经找到了，没有用处了）
  • 如果 当前遍历的温度 小于等于 栈顶对应的温度，那么我们就将当前温度的索引压入栈，保持栈的单调性

当遍历完成，如果栈中还有元素，那么说明 其对应的温度 是没有下一个更高温度的，其结果默认为 0，符合要求。

func dailyTemperatures(temperatures []int) []int {

    stack := make([]int, n) 
    ans := make([]int, n)
    for i, tem := range temperatures {
        for len(stack) != 0 && tem > temperatures[stack[len(stack)-1]] {
            ans[stack[len(stack)-1]] = i - stack[len(stack)-1] 
            stack = stack[:len(stack)-1]
        }
        stack = append(stack, i)
    }
    return ans
}

题目：给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

思路：

对每一个柱子，需要获取到它左右两边的第一个小于该柱子高度的柱子的位置，以当前柱子为高度，左右两边第一个小于该高度的柱子之间的距离作为宽度求出当前柱子能勾勒出的矩形的面积，记录下最大值。—— 也即，最大面积的高度肯定是heights中的其中一个，所以算出以每个height值为高度时的maxSize值，就可找到最终的最大面积。

那么对每一个柱子，如何获取到柱子左右两边第一个小于当前高度的柱子的位置呢？我们可以使用 left[] 和 right[] 两个数组 进行记录，规定：

  • left[i] 表示 柱子[i] 左边第一个小于 柱子[i] 高度的柱子的索引位置，例如 柱子5 对应的是 left[2] = 1
  • right[i] 表示 柱子[i] 右边第一个小于 柱子[i] 高度的柱子的索引位置，例如 柱子5 对应的是 right[2] = 4

结合栈，可以遍历数组一遍，即可把 left[] 和 right[] 都填满，具体方式：

遍历数组时，在遍历到当前元素时，只能确定出当前元素的左边界，以及能确定出部分过往元素的右边界。

func largestRectangleArea(heights []int) int {
    n := len(heights) 
    left, right := make([]int, n), make([]int, n) 
    stack := []int{}
    for i := 0; i < n; i++ {
        left[i] = -1
        right[i] = n
    }

    for i := 0; i < n; i++ {
        for len(stack) != 0 && heights[stack[len(stack)-1]] >= heights[i] {
            top := stack[len(stack)-1] 
            right[top] = i 
            stack = stack[:len(stack)-1]
        } 
        if len(stack) != 0 {
            left[i] = stack[len(stack)-1]
        }

        stack = append(stack, i)
    }
    ans := 0
    for i := 0; i < n; i++ {
        ans = max(ans, heights[i]*(right[i]-left[i]-1));
    }
    return ans
}

注意：

  1. stack这种动态变化的切片初始化时一定要 []int{} ，这样 len(stack) 才能反应真实的元素数量；make([]int, n) 是一个有固定长度的栈，里面塞满了默认值0；
  2. 相比之下，left 和 right 确实比较适合初始化时就设置长度，这样即使有位置因为不符合条件而没被遍历到，也会拥有默认值 0 。
  3. 思路further explanation：在遍历到当前数时，如果次数比栈顶的index指向的数小，那么 当前遍历数 就是 栈顶index指向数 的 右边第一个较小值；这么连环消掉之后，此时的 栈顶index指向数 因为比 当前遍历数 要小（或相等）而留在了栈里，所以此时的 栈顶index指向数 就变成了当前遍历数的 左边第一个较小值。
  4. 每次靠栈去做一些抵消的逻辑的时候，记得用当前遍历数抵消掉符合条件的栈顶之后，要把当前遍历数放回栈里，for 后续别的遍历数来抵消它。

func searchMatrix(matrix [][]int, target int) bool {

            right = mid
        } else {

        }

func searchRange(nums []int, target int) []int {
    return []int{ findMost(nums, target, true), findMost(nums, target, false) }
}

func findMost(nums []int, target int, isLeft bool) int {
    n := len(nums)
    left, right := 0, n-1 
    tmpIdx := -1
    for left <= right {
        mid := (left + right) / 2 
        if nums[mid] > target {
            right = mid-1
        } else if nums[mid] < target {
            left = mid+1 
        } else {
            tmpIdx = mid 
            if isLeft {
                right = tmpIdx-1
            } else {
                left = tmpIdx+1
            }
        }
    }
    return tmpIdx
}

注意：

  1. 不断地往边界上逼！
  2. 最后一个达成 nums[mid] == target 的mid值才能进入到else分支里面改变tmpIdx的值，所以最后返回tmpIdx！

            left = mid+1
        } else if nums[mid] < nums[right] {
            right = mid
        }
    }

此时拿 target 和 nums[right] 进行比较，就能知道target在哪一段：

  • nums[right] < target，则 target 在第一升序段，在其内进行二分查找；
  • nums[right] > target，则 target 在第二升序段，在其内进行二分查找；
  • nums[right] == target 则直接返回 right；
func search(nums []int, target int) int {
    n := len(nums) 
    left, right := 0, n-1 
    for left < right {
        mid := (left+right) / 2 
        if nums[mid] < nums[right] {
            right = mid
        } else if nums[mid] > nums[right] {
            left = mid+1
        }
    }
    min := left 
    if target > nums[n-1] {
        left = 0
        right = min-1
    } else {
        left = min
        right = n-1
    }
    for left <= right {
        mid := (left+right) / 2 
        if nums[mid] == target {
            return mid
        } else if nums[mid] < target {
            left = mid+1
        } else if nums[mid] > target {
            right = mid-1
        }
    } 
    return -1
}

4. 寻找两个正序数组的中位数 - Hard#

题目：给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。

算法的时间复杂度应该为 O(log (m+n)) 。

思路：

既然要 O(log(m+n)) 的时间复杂度，那就要二分了。

总体来说：把 nums1 和 nums2 各自中间砍一刀，左1+左2 = 新左、右1+右2=新右；并且保证 nums1和nums2总元素为偶数时，新左和新右元素数相同，否则新左比新右多1。

  • 把 nums1 和 nums2 中长度更短的换成 nums1 ，方便点；
  • 用 nums1 的 left=0 和 right=m 把 nums1 的切割线 i := (left + right) / 2 先定义出来；
  • right =m 是因为 线是割在 元素后面的，所以可能会取到m —— 那这个时候的意思就是：整个 nums1 都分进“新左”；
  • nums2 的 切割线 j 由 i + j = (m + n + 1) / 2 推导得 j := (m + n + 1) / 2 - i ；
  • i 和 j 分别代表了 切割后的“新左” 包括了nums1的前i个元素和nums2的前j个元素；
  • j := (m + n + 1) / 2 - i 的 “+1” 是为了保证“新左”永远比“新右”多一个数or相等；
  • 用 i 和 j 去给 left1, right1, left2, right2 赋值；—— 注意边界情况！
  • 根据 left1和right2 以及 left2和right1 的大小情况进行 left、right移动：
  • left1 ≤ right2 && left2 ≤ right1 —— 新左、新右分对了：
  • 如果 m+n 为奇数：中位数是新左里最大的数 —— max(left1, right1)；
  • 如果 m+n 为偶数：中位数是 (新左里最大的数+新右里最小的数)/2 —— max(left1, left2)+min(right1, right2)/2 ；
  • left1 > right2 说明 nums1的左边切多了 —— 切割左移（i 变小） right = i-1；
  • left2 > right1 说明 nums2的左边切少了 —— 切割右移（i 变大-j变小）left= i+1；
  • left 和 right的变动本质还是为了控制 i 和 j 变动；
func findMedianSortedArrays(nums1 []int, nums2 []int) float64 {
    m, n := len(nums1), len(nums2) 
    if m > n {
        nums1, nums2 = nums2, nums1
        m, n = n, m
    } 

    left, right := 0, m
    for left <= right {
        i := (left + right) / 2 
        j := (m + n + 1) / 2 - i 

        var left1, right1, left2, right2 int

        if i == 0 {
            left1 = math.MinInt32
        } else {
            left1 = nums1[i-1]
        }
        if i == m {
            right1 = math.MaxInt32
        } else {
            right1 = nums1[i]
        }

        if j == 0 {
            left2 = math.MinInt32
        } else {
            left2 = nums2[j-1]
        }
        if j == n {
            right2 = math.MaxInt32
        } else {
            right2 = nums2[j]
        }

        if left1 > right2 {
            right = i-1
        } else if left2 > right1 {
            left = i+1
        } else {
            if (m+n)%2 == 1 {
                return float64(max(left1, left2))
            } else {
                return float64(max(left1, left2)+min(right1, right2))/2
            }
        }
    }
    return 0
}

注意：

  1. go里面的最大数/最小数：math.MaxInt32/math.MinInt32；
  2. Go 必须写 float64()，不是 float() 。

160. 相交链表 - Easy#

题目：给你两个单链表的头节点 headA 和 headB ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 null 。

思路：如果两个指针同时遍历两个链表，其实两个指针是不能够同时遍历到相交的起始节点的。

那么这里换个思路：指针p1遍历完链表A后接着遍历链表B，而指针p2遍历完链表B后接着遍历链表A

如此那么两个指针就一定会同时遍历到两个链表的相交的起始节点。

func getIntersectionNode(headA, headB *ListNode) *ListNode {
    if headA == nil || headB == nil {
        return nil
    }
    pA, pB := headA, headB 
    for pA != pB {
        if pA == nil {
            pA = headB
        } else {
            pA = pA.Next
        }

        if pB == nil {
            pB = headA
        } else {
            pB = pB.Next
        }
    }
    return pA
}

注意：

  • 这里当已经扫描到A或B的队尾要移动pA或pB指针的时候，不要用 pA.Next == nil 去判断然后直接 pA.Next = headB，这样反而会把A的末尾连上B然后造成死循环！
  • 直接用pA是否为空来判断，然后让pA自己指向B队头 pA = headB。

206. 反转链表 - Easy#

题目：给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。

思路：定义 pre 指针(指向前一个元素)和 cur 指针(指向当前元素)，遍历链表，在遍历的过程中不断的把 链表节点之间的 指针进行反转，即 cur.next = pre。接着 pre 和 cur 指针都向后移动，接着重复上述过程。直到最后，cur 会移动到 null，而 pre 会移动到最后一个节点。此时就可以返回了，因此，while 循环的条件应该是 cur != null，且应当返回 pre 指针。这个题看动画或结合图才会比较清楚。

func reverseList(head *ListNode) *ListNode {
    var prev *ListNode 
    curr := head 
    for curr != nil {
        next := curr.Next 
        curr.Next = prev 
        prev = curr 
        curr = next
    }
    return prev
}

注意：prev 的实际意义是，前面已经翻转好的链表的队头，而不是只是前一个这么简单！

234. 回文链表#

题目：给你一个单链表的头节点 head ，请你判断该链表是否为回文链表。如果是，返回 true ；否则，返回 false 。

思路：

方案一：将链表的内容复制到数组，再使用数组双指针一头一尾遍历判断是否回文。

func isPalindrome(head *ListNode) bool {
    p := head 
    nums := []int{}
    for p != nil {
        nums = append(nums, p.Val) 
        p = p.Next
    } 
    for i := 0; i < len(nums) / 2; i++ {
        if nums[i] != nums[len(nums)-i-1] {
            return false
        }
    }
    return true
}

方案二(优)：寻找中间节点+反转后半段的链表。再用链表双指针一头一尾都向中间走，遍历判断是否回文。

func isPalindrome(head *ListNode) bool {
    p := head 
    middleNode := findMiddleNode(p) 
    head2 := flipList(middleNode)
    for head2 != nil {
        if head.Val != head2.Val {
            return false
        }
        head = head.Next
        head2 = head2.Next
    }
    return true
}

func findMiddleNode(head *ListNode) *ListNode {
    fast, slow := head, head 
    for fast != nil && fast.Next != nil {
        fast = fast.Next.Next
        slow = slow.Next
    }
    return slow 
}

func flipList(head *ListNode) *ListNode {
    curr := head 
    var prev *ListNode = nil
    for curr != nil {
        next := curr.Next 
        curr.Next = prev 
        prev = curr 
        curr = next
    }
    return prev
}

注意：

  1. 如果链表本身是 1 -> 2 -> 3 -> 4 -> 5，那么middleNode会定位到 3 节点上，然后 3 → 4 → 5 这部分会反转成 5 → 4 → 3 ，但是只会影响到 3.Next 变成 nil，而不会影响 2-3 之间的连接关系；所以最后链表会变成 1 → 2 → 3 ← 4 ← 5 ，并且同时 head 仍指向 1 而 head2 指向 5。
  2. 然后同时让 head 和 head2 往中间移动，检查每轮指向的节点Val是否相同！

141. 环形链表 - Easy#

题目：给你一个链表的头节点 head ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：pos 不作为参数进行传递 。仅仅是为了标识链表的实际情况。

*如果链表中存在环* ，则返回 true 。 否则，返回 false 。

思路：快慢指针，初始时快慢指针都指向head头节点，慢指针每次走一步，快指针每次走两步，如果链表中存在环，那么快指针一定会追上慢指针(套圈)，也就是说两个指针一定会相遇。但如果快指针或快指针的next指针指向空则说明链表中不存在环。

func hasCycle(head *ListNode) bool {
    slow := head; 
    fast := head; 
    for fast != nil && fast.Next != nil {
        fast = fast.Next.Next
        slow = slow.Next
        if fast == slow {
            return true
        }
    }
    return false
}

142. 环形链表 II - Mid#

题目：给定一个链表的头节点 head ，返回链表开始入环的第一个节点。 *如果链表无环，则返回 null。*

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 pos 是 -1，则在该链表中没有环。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。不允许修改 链表。

思路：由前一题的基础，我们知道如果有环，slow 每次走一步，fast 每次走两步，那么 slow 和 fast 会在某一点相遇，如果不存在环，则 fast 或 fast.next 会指向null。

假设链表中有环，那么当 slow 和 fast 相遇时，我们应该如何找到环的第一个节点。

此时由数学推理而出，只需要将 slow 或 fast 任意选一个指针 重新指向head。

然后 slow 和 fast 同时每次走一步，最终就会在 链表的 环的第一个节点相遇。

func detectCycle(head *ListNode) *ListNode {
    fast, slow := head, head 
    for fast != nil && fast.Next != nil {
        slow = slow.Next 
        fast = fast.Next.Next
        if slow == fast {
            break
        }
    }
    if fast == nil || fast.Next == nil {
        return nil 
    }
    
    fast = head
    for fast != slow {
        fast = fast.Next 
        slow = slow.Next
    }
    return slow
}

注意：一定要注意从第一个for循环出来的时候，既有可能是 slow == fast ，也有可能是 fast != nil || fast.Next != nil 所以一定要记得验空！

21. 合并两个有序链表 - Mid#

题目：将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

思路：当 l1 和 l2 都不是空链表时，判断 l1 和 l2 哪一个链表的头节点的值更小，将较小值的节点添加到结果里，并且将对应链表中的节点向后移一位。不断循环。

我们设定一个哨兵节点 dummy，这可以在最后让我们比较容易地返回合并后的链表。

在循环终止的时候， l1 和 l2 至多有一个是非空的。由于输入的两个链表都是有序的，所以不管哪个链表是非空的，它包含的所有元素都比前面已经合并链表中的所有元素都要大。这意味着我们只需要简单地将非空链表接在合并链表的后面，并返回合并链表即可。

func mergeTwoLists(list1 *ListNode, list2 *ListNode) *ListNode {
    dummy := &ListNode{} 
    p := dummy
    l1, l2 := list1, list2 
    for l1 != nil && l2 != nil {
        if l1.Val < l2.Val {
            p.Next = l1 
            l1 = l1.Next
        } else {
            p.Next = l2 
            l2 = l2.Next 
        }
        p = p.Next
    }
    if l1 != nil {
        p.Next = l1
    }
    if l2 != nil {
        p.Next = l2
    }
    return dummy.Next
}

2. 两数相加 - Mid#

题目：给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

思路：

  • 342 逆序存储为：2 → 4 → 3
  • 465 逆序存储为：5 → 6 → 4
  • 342+465=807 逆序存储为：7 → 0 → 8

题目里逆序存储数字在链表中，其实会让我们的计算更方便！因为两个数的加法都是从个位数开始相加的因此，只需要顺序遍历两条链表的节点，进行相加，注意保留好进位即可。

func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
    if l1 == nil && l2 == nil {
        return nil
    }
    p1, p2 := l1, l2 
    var n1, n2 int
    carry, sum := 0, 0
    dummy := &ListNode{}
    curr := dummy
    for p1 != nil || p2 != nil || carry != 0 {
        n1, n2 = 0, 0
        if p1 != nil {
            n1 = p1.Val
            p1 = p1.Next
        }
        if p2 != nil {
            n2 = p2.Val
            p2 = p2.Next
        } 
        sum = n1 + n2 + carry 
        temp := sum % 10 
        carry = sum / 10
        curr.Next = &ListNode{Val: temp}
        curr = curr.Next
    }
    return dummy.Next
}

注意：l1和l2的长度不一样长，所以说后面可能只有一个链表是不为空的，就照常加和，空的链表在当前节点的值当做0；除了判断两个链表是否为空，还要注意看进位是否还有值！！！

19. 删除链表的倒数第N个结点#

题目：给你一个链表，删除链表的倒数第 n个结点，并且返回链表的头结点。

思路：要删除倒数第n个结点，那么只需要找到倒数第n+1个节点。

假设倒数第n+1个节点为 p，再通过 p.next = p.next.next 即可删除倒数第n个节点。且我们要考虑一种特殊情况，即如果链表长度为10，且要删除倒数第10个节点，即要删除第一个节点。那么就要找到倒数第11个节点，可链表并没有倒数第11个节点，这时候其实就是需要使用虚拟头结点。

现在的问题在于如何找到倒数第n+1个节点，这里有个规律(记住或者自己在脑子里用实例模拟跑一下)：

  • 使用快慢指针，都从dum虚拟头结点出发，让快指针先走n+1步；
  • 注意边界情况如果链表的长度小于n则不符合题意（题意要求删除倒数第n个结点）；
  • 即如果fast先走的过程中，如果出现fast==null，即说明链表长度小于n → 直接返回head；
  • 然后快慢指针同时每次走一步，当快指针走到 null 时，慢指针刚好到达倒数第n+1个结点。

例如 // dum -> 1 -> 2 -> 3 -> 4

// 若n = 2 即要删除节点3 则需要找到 节点2 (倒数第3个节点)

// fast 从dum出发，先走 n+1 即 3 步，走完 fast 指向 节点3

// fast 和 slow 同时走，当 fast 指向null时，slow 会指向 节点2 (倒数第3个节点)

func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummy := &ListNode{Val: -1, Next: head} 
    fast, slow := dummy, dummy
    for i := 0; i < n+1; i++ {
        if fast == nil {
            return head
        }
        fast = fast.Next
    }
    for fast != nil {
        fast = fast.Next 
        slow = slow.Next
    }
    slow.Next = slow.Next.Next
    return dummy.Next
}

题目：给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

方案一：递归，符合递归的特性，注意每一分组翻转后，需要将递归结果连接到前一组节点后面

1、从头到尾 进行 递深 (递归深入的过程)

2、会在尾部开始交换（即遇到了递归的终止条件后，需要开始交换了）

3、把交换后的节点返回给上一部分 即归的过程

func swapPairs(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head 
    } 
    left := head 
    right := head.Next 
    left.Next = swapPairs(right.Next) 
    right.Next = left
    return right
}

25. K个一组翻转链表 - Hard#

题目：给你链表的头节点 head ，每 k个节点一组进行翻转，请你返回修改后的链表。

k 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 k的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

思路：符合递归的特性

  • 递归的终止条件是 当前区间不满足k个节点，所以不需要反转，就直接返回那个区间的头节点，那么实际上需要去数一遍当前区间是否满足k个。
  • 递归每一层级的任务是反转当前区间的链表。
  • 注意分组翻转后，当前区间需要连接下一个反转区间返回的头节点。
func reverseKGroup(head *ListNode, k int) *ListNode {
    tail := head
    for i := 0; i < k; i++ {
        if tail == nil {
            return head
        }
        tail = tail.Next
    } 
    p := head 
    var prev *ListNode = nil 
    for p != tail {
        next := p.Next 
        p.Next = prev 
        prev = p 
        p = next
    } 
    head.Next = reverseKGroup(p, k) 
    return prev
}

注意：

  1. 先判断当前分到的这个子链表足不足够 k，若不足则说明这是最后一段且不足 k 个，不满足翻转条件，直接返回 head 。
  2. 然后开始对本子链表的处理：
  3. 从 head 一直到 tail （刚刚算过从head开始k个节点会截止到哪个节点）前的那一个节点都是本轮要翻转的子链表；
  4. 所以对于从 head 到 tail前一位每个节点，都采用反转链表方式进行处理；
  5. 从 for 循环break出来之后，此时的 p 和 tail 相等，都是下一段要翻转的子链表的第一个节点，且 head 翻转前是本次子链表的头结点，翻转后会变成本段子链表的尾结点，要让这个尾结点接上 下一段子链表翻转后的头节点，所以 head.Next = reverseKGroup(p, k) ；
  6. 然后 prev 是本轮要翻转的子链表翻转后的头结点，所以返回 prev。

138. 随机链表的复制 - Mid#

题目：给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 深拷贝。 深拷贝应该正好由 n 个 全新 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点 。

例如，如果原链表中有 X 和 Y 两个节点，其中 X.random --> Y 。那么在复制链表中对应的两个节点 x 和 y ，同样有 x.random --> y 。

返回复制链表的头节点。

func copyRandomList(head *Node) *Node {
    if head == nil {
        return head

    mp := map[*Node]*Node{} 
    p := head 
    for p != nil {
        newNode := &Node{Val: p.Val}
        mp[p] = newNode
        p = p.Next
    }
    p = head
    for p != nil {
        // temp := mp[p]

        p = p.Next
    }

}

func sortList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    } 
    slow := head 
    fast := head.Next 
    for fast != nil && fast.Next != nil {
        slow = slow.Next 
        fast = fast.Next.Next
    } 
    secondHead := slow.Next 
    slow.Next = nil 
    return mergeLists(sortList(head), sortList(secondHead))
}

func mergeLists(l1 *ListNode, l2 *ListNode) *ListNode {
    if l1 == nil && l2 == nil {
        return nil
    }
    dummy := &ListNode{} 
    p := dummy 
    p1, p2 := l1, l2
    for p1 != nil && p2 != nil {
        if p1.Val > p2.Val {
            p.Next = p2
            p2 = p2.Next
        } else {
            p.Next = p1
            p1 = p1.Next
        }
        p = p.Next
    }
    if p1 != nil {
        p.Next = p1
    }
    if p2 != nil {
        p.Next = p2
    }
    return dummy.Next
}

146. LRU 缓存 - Hard#

题目：请你设计并实现一个满足 LRU (最近最少使用) 缓存 约束的数据结构。

实现 LRUCache 类：

  • LRUCache(int capacity) 以 正整数 作为容量 capacity 初始化 LRU 缓存
  • int get(int key) 如果关键字 key 存在于缓存中，则返回关键字的值，否则返回 1 。
  • void put(int key, int value) 如果关键字 key 已经存在，则变更其数据值 value ；如果不存在，则向缓存中插入该组 key-value 。如果插入操作导致关键字数量超过 capacity ，则应该 逐出 最久未使用的关键字。

函数 get 和 put 必须以 O(1) 的平均时间复杂度运行。

思路：使用哈希表和双向链表实现

  • 函数 get 和 put 必须以O(1)的平均时间复杂度运行，可以使用哈希表
  • LRU 算法需要淘汰最久未使用的 key，因此可以使用双向链表: 维护访问顺序，实现O(1)时间复杂度的插入和删除。如果使用了某个key，先把该key从链表中删除，然后把该key重新插入到链表头部，那么一直没有被使用的key就会逐渐跑到链表尾部，此时如果要淘汰key，只需要从链表尾部删除元素即可

get操作：

  1. 哈希表查找：O(1)找到节点
  2. 链表调整：将节点移到头部（先删除再头部插入）O(1)

put操作：

  • key存在：更新值，将节点移到头部（先删除再头部插入）O(1)
  • key不存在：
  1. 如果容量满：删除尾部节点 O(1)
  2. 创建新节点插入头部 O(1)
  3. 哈希表添加映射 O(1)
type DLinkedNode struct {
    key, val int 
    prev, next *DLinkedNode
}

type LRUCache struct {
    size, capacity int 
    cache map[int]*DLinkedNode
    head, tail *DLinkedNode
}

func initDLinkedNode(key, value int) *DLinkedNode {
    return &DLinkedNode{
        key: key, 
        val: value,
    }
}

func Constructor(capacity int) LRUCache {
    lru := LRUCache{
        capacity: capacity, 
        cache: map[int]*DLinkedNode{}, 
        head: initDLinkedNode(0, 0), 
        tail: initDLinkedNode(0, 0),
    }
    lru.head.next = lru.tail 
    lru.tail.prev = lru.head 
    return lru
}

func (this *LRUCache) Get(key int) int {
    if _, ok := this.cache[key]; !ok {
        return -1
    }
    node := this.cache[key] 
    this.removeNode(node)
    this.addToHead(node)
    return node.val
}

func (this *LRUCache) Put(key int, value int)  {
    if _, ok := this.cache[key]; ok {
        node := this.cache[key] 
        this.removeNode(node) 
        node.val = value
        this.addToHead(node) 
        return 
    } 
    node := initDLinkedNode(key, value)
    this.cache[key] = node
    this.addToHead(node)
    this.size++
    for this.size > this.capacity {
        removed := this.removeTail()
        delete(this.cache, removed.key) 
        this.size--
    }
}

func (this *LRUCache) removeNode(node *DLinkedNode) {
    node.next.prev = node.prev 
    node.prev.next = node.next
}

func (this *LRUCache) addToHead(node *DLinkedNode) {
    node.next = this.head.next 
    node.prev = this.head
    this.head.next.prev = node
    this.head.next = node
}

func (this *LRUCache) removeTail() *DLinkedNode {
    node := this.tail.prev 
    this.removeNode(node) 
    return node
}

func preorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }

    stack := []*TreeNode{} 
    stack = append(stack, root) 
    for len(stack) != 0 {
        top := stack[len(stack)-1] 
        stack = stack[:len(stack)-1]
        res = append(res, top.Val)
        if top.Right != nil {
            stack = append(stack, top.Right)
        }
        if top.Left != nil {
            stack = append(stack, top.Left)
        }
    }
    return res
}

  • 用dfs找到从根节点到4的路径：3 5 2 4

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    tempPath := []*TreeNode{} 
    pathP := []*TreeNode{} 
    pathQ := []*TreeNode{} 
    var res *TreeNode = nil

    dfs(root, p, q, &tempPath, &pathP, &pathQ) 

    for i := 0; i < len(pathP) && i < len(pathQ); i++ {
        if pathP[i] == pathQ[i] {
            res = pathP[i]
        } else {
            break
        }
    }

    return res
}

func dfs(root, p, q *TreeNode, tempPath, pathP, pathQ *[]*TreeNode) {
    if root == nil {
        return
    } 
    *tempPath = append(*tempPath, root) 

    if root == p {
        *pathP = make([]*TreeNode, len(*tempPath))
        copy(*pathP, *tempPath)
    }
    if root == q {
        *pathQ = make([]*TreeNode, len(*tempPath))
        copy(*pathQ, *tempPath)
    }

    if len(*pathP) == 0 || len(*pathQ) == 0 {
        dfs(root.Left, p, q, tempPath, pathP, pathQ) 
        dfs(root.Right, p, q, tempPath, pathP, pathQ) 
    }

    *tempPath = (*tempPath)[:len(*tempPath)-1]
}

124. 二叉树中的最大路径和 - Hard#

题目：二叉树中的 路径 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 至多出现一次 。该路径 至少包含一个 节点，且不一定经过根节点。

路径和 是路径中各节点值的总和。

给你一个二叉树的根节点 root ，返回其 最大路径和 。

思路：对每个节点，计算“以它为最高点的最大路径”，在过程中记录全局最大值。

我们把大问题分解成小问题：对于每个节点，计算“以它为转折点的最大路径和”

什么是“转折点”？比如路径 2-1-3，1 就是转折点，路径从左子树来到右子树。

关键概念

  1. 单边最大路径：从某个节点往下走（只能选左或右一支）能获得的最大和
  2. 以当前节点为转折点的最大路径：左最大单边路径 + 节点值 + 右最大单边路径

算法步骤

  1. 从叶子节点开始计算（递归到底部）
  2. 对每个节点：
  • 计算左子树的“单边最大路径”（如果是负数就取0，因为可以不要）
  • 计算右子树的“单边最大路径”
  • 更新全局最大值：最大路径和 = max(当前最大值, 左+右+当前节点值)
  • 返回给父节点 为什么返回的是单边路径？：当前节点的单边最大路径 = 当前节点值 + max(左单边, 右单边)因为递归时，当前节点需要告诉父节点：“从我这里往上，最好的情况是多少”。父节点只能选择左或右一支，所以返回最大的单边。

 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */

func maxPathSum(root *TreeNode) int {
    maxSum = math.MinInt32
    return max(maxGain(root), maxSum)
}

func maxGain(node *TreeNode) int {
    if node == nil {
        return 0 
    }

    leftGain := max(0, maxGain(node.Left))
    rightGain := max(0, maxGain(node.Right))
    curGain := leftGain + rightGain + node.Val 

    maxSum = max(maxSum, curGain) 

    return max(leftGain, rightGain) + node.Val
}

46. 全排列 - Mid#

题目：给定一个不含重复数字的数组 nums ，返回其 *所有可能的全排列* 。你可以 按任意顺序 返回答案。

思路：回溯法，可参考思路讲解：46. 全排列 、labuladong 视频题解

全排列的核心特征是：每个元素必须出现且仅出现一次，元素的顺序不同属于不同的排列。

本题的本质是遍历一棵决策树：

每个节点代表当前的排列路径，每条从根到叶的路径对应一个完整的全排列：

  • 选择：从数组中选一个未使用的元素，加入当前排列路径。
  • 递归：基于当前选择，继续递归选择下一个元素，直到路径长度等于数组长度（得到一个完整排列）。
  • 回溯：递归返回后，撤销当前选择（将元素移出路径、标记为未使用），尝试下一个可能的元素。
var res [][]int

func permute(nums []int) [][]int {
    n := len(nums) 
    used := make([]bool, n) 
    path := []int{} 
    res = [][]int{}

    backtracking(nums, used, path)
    return res
}

func backtracking(nums []int, used []bool, path []int) {
    if len(path) == len(nums) {
        // res = append(res, path) // 切片是引用传递的！
        temp := make([]int, len(path)) 
        copy(temp, path) 
        res = append(res, temp)
        return
    }
    for i := 0; i < len(nums); i++ {
        if used[i] {
            continue
        }
        path = append(path, nums[i]) 
        used[i] = true 
        backtracking(nums, used, path)
        used[i] = false 
        path = path[:len(path)-1]
    }
}

注意：切片是引用传递的，所以如果每次path里的元素数量和nums长度一样，把当前path加进res之后，后续对path的修改其实会影响res里面存的切片值，所以拷贝一下再存进去！

func exist(board [][]byte, word string) bool {
    m, n := len(board), len(board[0]) 
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            visited := make([][]bool, m) 
            for k := 0; k < m; k++ {
                visited[k] = make([]bool, n)
            }
            if findWord(board, word, visited, 0, i, j) {
                return true 
            }
        }
    }
    return false

func findWord(board [][]byte, word string, visited [][]bool, idx, row, col int) bool {
    if idx == len(word) {
        return true
    }

    m, n := len(board), len(board[0]) 
    if row < 0 || row >= m || col < 0 || col >= n || board[row][col] != word[idx] || visited[row][col] {
        return false
    }

    visited[row][col] = true 

    up := findWord(board, word, visited, idx+1, row-1, col)
    down := findWord(board, word, visited, idx+1, row+1, col)
    right := findWord(board, word, visited, idx+1, row, col+1)
    left := findWord(board, word, visited, idx+1, row, col-1) 

    isValid := up || down || right || left 

    visited[row][col] = false 

    return isValid
}

  2. 对于每一个在路径里被找到处理的节点，都只管当前节点是否有越界/和word不一致的问题，然后把处理推向它周围的四个点。

    chessboard := make([][]byte, n) 
    for row := range chessboard {
        chessboard[row] = make([]byte, n)
        for col := 0; col < n; col++ {
            chessboard[row][col] = '.'
        }
    }
    placeChess(chessboard, n, 0)

func placeChess(chessboard [][]byte, n int, row int) {
    if row == n {
        tmp := make([]string, n)
        for i := range chessboard {
            tmp[i] = string(chessboard[i])
        }
        res = append(res, tmp)
        return
    }

    for j := 0; j < n; j++ {
        if isValid(chessboard, row, j) {
            chessboard[row][j] = 'Q' 
            placeChess(chessboard, n, row+1) 
            chessboard[row][j] = '.'
        }
    }
}

func isValid(chessboard [][]byte, row int, col int) bool {
    n := len(chessboard)
    for i := row-1; i >= 0; i-- {
        if chessboard[i][col] == 'Q' {
            return false
        }
    }

    for i, j := row-1, col-1; i >= 0 && j >= 0; i, j = i-1, j-1 {
        if chessboard[i][j] == 'Q' {
            return false
        }
    }

    for i, j := row-1, col+1; i >= 0 && j < n; i, j = i-1, j+1 {
        if chessboard[i][j] == 'Q' {
            return false
        }
    }
    return true
}

题目：给定一个长度为 n 的 0 索引整数数组 nums。初始位置为 nums[0]。

  • 0 <= j <= nums[i]
  • i + j < n

思路：贪心算法，通过局部最优解得到全局最优解，

  • 如果我们「贪心」地进行正向查找，即假设站在下标 i 位置时，可以跳 [0-num[i]] 步远，但是跳几步呢，我们应该要找到下一次能让你跳的更远的位置
  • 例如，对于数组 [2,3,1,2,4,2,3]，初始位置是下标 0，从下标 0 出发，最远可到达下标 2。下标 0 可到达的位置中，下标 1 的值是 3，从下标 1 出发可以达到更远的位置，因此第一步到达下标 1。
  • 从下标 1 出发，最远可到达下标 4。下标 1 可到达的位置中，下标 4 的值是 4 ，从下标 4 出发可以达到更远的位置，因此第二步到达下标 4。
  • 在遍历数组时，只需要遍历到倒数第二个位置，最后一个位置是不需要再跳的。
func jump(nums []int) int {
    curRangeEnd, nextRangeEnd, jumps := 0, 0, 0
    for i := 0; i < len(nums) - 1; i++ {
        nextRangeEnd = max(nextRangeEnd, nums[i]+i) 
        if i == curRangeEnd {
            curRangeEnd = nextRangeEnd 
            jumps++
        }
    }
    return jumps
}

注意：

  1. 其实概括下来就是：遍历每一个可到达位置的最远到达位置，然后贪心，每次都选可到达最远的路径；每一次更新当前边界的时候，其实就是本轮要遍历的已经遍历完了，所以要执行下一跳了—— jumps++。

func partitionLabels(s string) []int {

    res := []int{}

        lastPos[s[i] - 'a'] = i

    for i := 0; i < len(s); i++ {
        end = max(end, lastPos[s[i]-'a'])

        if i == end {
            res = append(res, end-start+1)
            start = end+1
        }
    }
    return res
}

  • 假设偷窃最后一间房(那么倒数第二间就不能偷了)，那么偷盗 [1、2、3、1] 四间房屋的最大利润就变成了偷盗 [1、2] 两间房屋的最大利润 + 偷盗最后一间房屋所能获得的金额（即1）

        dp[i] = max(dp[i-2] + nums[i-1], dp[i-1])
    }

func coinChange(coins []int, amount int) int {
    dp := make([]int, amount+1) 
    for i := range dp {
        dp[i] = amount+1
    }
    dp[0] = 0
    for i := 1; i < amount+1; i++ {
        for j := 0; j < len(coins); j++ {
            if i >= coins[j] {
                dp[i] = min(dp[i], dp[i-coins[j]]+1)
            }
        }
    }
    if dp[amount] > amount{
        return -1
    } else {
        return dp[amount]
    }
}

题目：给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32-位 整数。

思路：动态规划。

以[1,2,3,4]举例：

  • 以1结尾的连续子数组的最大乘积值为1，记为dp[0]；
  • 以2结尾的连续子数组的最大乘积值为2，记为dp[1]；
  • 以3结尾的连续子数组的最大乘积值为6，记为dp[2]；
  • 以4结尾的连续子数组的最大乘积值为24，记为dp[3]；

观察规律，可以发现规律，dp[3] = dp[2] x nums[3]，因此dp[n] = dp[n-1] x nums[n]。

但是如果数组中存在负数，例如[-1,-2,-3,-4]举例：

  • 以-1结尾的连续子数组的最大乘积值为-1，记为dp[0]；
  • 以-2结尾的连续子数组的最大乘积值为2，记为dp[1]；
  • 以-3结尾的连续子数组的最大乘积值 如果按照上面的公式应该是 dp[2] = dp[1] x nums[2] = -6，但实际上以-3结尾的连续子数组的最大乘积值应该是 -2x-3 = 6，因此可知前面推导的公式是不适用于存在负数的情况，因为当前数是-3，如果已知前面的最小乘积值，且最小乘积值是负数 和 -3 相乘 就能得到一个更大的数；

因此其实在动态规划时需要同时维护以第i个元素结尾的连续子数组的最大乘积值和最小乘积值

  • cur_max[i]：代表以第i个元素结尾的连续子数组的最大乘积值；
  • cur_min[i]：代表以第i个元素结尾的连续子数组的最小乘积值；

由上述示例，可推导出 cur_max 和 cur_min 的规律如下：

  • cur_max[n] = Math.max { cur_max[n-1] x nums[n] , cur_min[n-1] x nums[n] ， nums[n] }；
  • cur_min[n] = Math.min { cur_max[n-1] x nums[n] , cur_min[n-1] x nums[n] ， nums[n] }；

边界条件：cur_max[0] = nums[0]、cur_min[0] = nums[0]。

func maxProduct(nums []int) int {
    maxRes, curMax, curMin := nums[0], nums[0], nums[0]
    for i := 1; i < len(nums); i++ {
        tempMax, tempMin := curMax, curMin

        curMax = max(tempMax*nums[i], tempMin*nums[i], nums[i])
        curMin = min(tempMax*nums[i], tempMin*nums[i], nums[i]) 

        maxRes = max(curMax, maxRes)
    }
    return maxRes
}

注意：

  1. 每一次循环都用 tempMax 和 tempMin 来存是因为：如果直接用 curMax 和 curMin 在里面计算，计算 curMin 的时候，curMax 是已经被更新的结果而不是之前的结果了，会导致本轮 curMin 计算出错！

func canPartition(nums []int) bool {
    sum, maxNum := 0, 0
    for _, num := range nums {
        sum += num 
        maxNum = max(maxNum, num)
    }

        return false
    }

    target := sum / 2
    if maxNum > target {
        return false
    }

    dp := make([]bool, target+1)
    dp[0] = true
    for _, v := range nums {
        for j := target; j >= v; j-- {
            dp[j] = dp[j] || dp[j-v]
        }
    }
    return dp[target]
}

func longestValidParentheses(s string) int {
    ans := 0
    stack := []int{-1}
    for i := 0; i < len(s); i++ {
        if s[i] == '(' {
            stack = append(stack, i)  
        } else {
            stack = stack[:len(stack)-1] 
            if len(stack)==0 {
                stack = append(stack, i) 
            } else {
                left := stack[len(stack)-1] 
                ans = max(ans, i - left)
            }
        }
    }
    return ans
}

func uniquePaths(m int, n int) int {
    dp := make([][]int, m) 
    for row := range dp {
        dp[row] = make([]int, n)
        dp[row][0] = 1
    }

    for j := range dp[0] {
        dp[0][j] = 1
    }

64. 最小路径和 - Mid#

题目：给定一个包含非负整数的 *m* x *n* 网格 grid ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。说明：每次只能向下或者向右移动一步。

思路：动态规划。

我们设定 从左上角(0,0)到右下角(i,j) 的最小路径和为 dp[i,j]，依照设定，则：

  • 从左上角(0,0)到(i,j-1)的最小路径和为dp[i,j-1]；
  • 从左上角(0,0)到(i-1,j)的最小路径和为dp[i-1,j]；

由于每次只能向右走或向下走，所以 dp[i,j] = Math.min (dp[i,j-1], dp[i-1,j]) + grid[i][j] 。

有了递推公式，只需要从 dp[0][0] 一层一层推导到 dp[i][j] 即可，边界条件dp[0][0] = grid[0][0]

其中第一行(只能从左边走过来)路径和累加左边的值 和 第一列(只能从上面走下来)路径和累加上面的值 即可

func minPathSum(grid [][]int) int {
    m, n := len(grid), len(grid[0]) 
    for i := 1; i < m; i++ {
        grid[i][0] += grid[i-1][0]
    }
    for j := 1; j < n; j++ {
        grid[0][j] += grid[0][j-1]
    }
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            grid[i][j] += min(grid[i-1][j], grid[i][j-1])
        }
    }
    return grid[m-1][n-1]
}

5. 最长回文子串 - Mid#

题目：给你一个字符串 s，找到 s 中最长的回文子串。

思路：双指针。

情况1：回文长度为奇数（如"bab"）

  • 想要判断是否回文串，我们可以枚举每一个字符，以每一个 单个字符为中心，定义L指针和R指针指向单个字符后，L和R向左右两边扩展，在L和R不越界的情况下，直到L和R所指字符不相等为止，在扩展过程中，记录下最长回文子串的长度和起始点。

情况2：回文长度为偶数（中心是两个字符，如"baab"）

  • 当回文长度为偶数时，我们的中心不再是单个字符了，而应该是两个字符为整体作为中心，因此例如L指向i，则R指向i+1，L和R向左右两边扩展，在L和R不越界的情况下，直到L和R所指字符不相等为止，在扩展过程中，记录下最长回文子串的长度和起始点。
func longestPalindrome(s string) string {
    **n := len(s)**
    resLen, resStart := 1, 0 
    left, right := 0, 0
    for i := 0; i < n; i++ {
        left, right = i, i
        for (left >= 0 && right < n) && (s[left] == s[right]) {
            if right - left + 1 > resLen {
                resLen = right - left + 1 
                resStart = left
            }
            left-- 
            right++
        }

        left, right = i, i+1
        for (left >= 0 && right < n) && (s[left] == s[right]) {
            if right - left + 1 > resLen {
                resLen = right - left + 1 
                resStart = left
            }
            left-- 
            right++
        }
    }
    return s[resStart:resStart+resLen]
}

注意：

  1. 对于以每一个 i 为中心点的可能性：我们都要奇数和偶数都判断，反正长度更长的那个会重叠掉 maxLen！

题目：给定两个字符串 text1 和 text2，返回这两个字符串的最长 公共子序列 的长度。如果不存在 公共子序列 ，返回 0 。

一个字符串的 子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

  • 例如，"ace" 是 "abcde" 的子序列，但 "aec" 不是 "abcde" 的子序列。

两个字符串的 公共子序列 是这两个字符串所共同拥有的子序列。

思路：动态规划。

假设 text1 = ...... a b c d e 总长度为m+1， text2 = ...... a c e 总长度为 n+1 （这里忽略前几位字符）

那么最后一个字符，text1中的e的索引为m，text2中的e的索引为n。

  • 假如 text1[m] == text2[n] 即e==e，原问题text1和text2的最长公共子序列就可以转换为
  • text1的从0到m-1区间 和 text2的从0到n-1区间 这两个子字符串的最长公共子序列 + 1；
  • 假如 text1[m] != text2[n] ，原问题text1和text2的最长公共子序列就可能存在于：
  • text1的从0到m-1区间 和 text2的从0到n区间 这两个子字符串的最长公共子序列；
  • 或者 text1的从0到m区间 和 text2的从0到n-1区间 这两个子字符串的最长公共子序列；
  • 原问题就可以转化为上述两者的较大值

综上所述，可以得到递推公式：f(0~m,0~n) =：

  • f(0~m-1,0~n-1) + 1，在text1[m] == text2[n] 的情况下；
  • Math.max(f(0~m-1,0~n),f(0~m,0~n-1)) ，在text1[m] != text2[n] 的情况下；

从上往下一层一层填表即可，最终答案为dp[len1][len2]。

表格中的第一行和第一列全部默认为0，表示空字符串的情况。

dp[i][j]：表示text1的前 i 个字符 和 text2的前 j 个字符的最长公共子序列长度。

func longestCommonSubsequence(text1 string, text2 string) int {
    m, n := len(text1), len(text2) 
    dp := make([][]int, m+1) 
    for i := 0; i < m+1; i++ {
        dp[i] = make([]int, n+1)
    }
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if text1[i] == text2[j] {
                dp[i+1][j+1] = dp[i][j] + 1
            } else{
                dp[i+1][j+1] = max(dp[i][j+1], dp[i+1][j])
            }
        }
    }
    return dp[m][n]
}

题目：给你两个单词 word1 和 word2， *请返回将 word1 转换成 word2 所使用的最少操作数* 。

  • 删除一个字符
  • 替换一个字符

假设 word1 = a b c ， word2 = a d c，定义两个指针i和j分别指向两个字符串的最后一个字符

目标是求 把 word1 转换成 word2 最小的编辑距离

当前 i 在word1中指向的字符是c，j在word2中指向的字符也是c，因此此时不需要任何的编辑，可知

  • f(i,j) = f(i-1,j-1)，在word1[i] = word2[j]的情况下
  • ---

假设 word1 = a b e ， word2 = a d c，此时 i 和 j 指向的 分别是 e 和 c，即 word1[i] != word2[j]的情况下，为了把word1转换成word2：

可以在 word1 的 i 处位置，插入元素或删除元素或替换元素，来使得word1[i] == word2[j]

  • 若插入元素c：则 word1=a b e c，word2=a d c 此时需要继续将word1的 [0,i] 转换为word2的 [0,j-1]
  • 则原问题转换为 f(i,j) = f(i,j-1)+1
  • 若删除元素：则 word1=a b ，word2=a d c 此时需要继续将word1的 [0,i-1] 转换为word2的 [0,j]
  • 则原问题转换为 f(i,j) = f(i-1,j)+1
  • 若替换元素：则 word1=a b c，word2=a d c 此时需要继续将word1的 [0,i-1] 转换为word2的 [0,j-1]
  • 则原问题转换为 f(i,j) = f(i-1,j-1)+1

因此在word1[i] != word2[j]的情况下，我们需要从上述三种情况，取得编辑距离最小的。

边界条件 f(0，0) = 0

填表：第一行的元素都是通过左边的元素进行状态转移，第一列的元素都是通过上边的元素进行状态转移；其余元素，则按照递推公式判断即可。

func minDistance(word1 string, word2 string) int {
    m, n := len(word1), len(word2) 
    dp := make([][]int, m+1) 
    for i := 0; i <= m; i++ {
        dp[i] = make([]int, n+1) 
        dp[i][0] = i
    }
    for j := 0; j <= n; j++ {
        dp[0][j] = j
    }

    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ { 
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1]
            } else {
                dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
            }
        }
    }
    return dp[m][n]
}

注意：

  1. 一定要注意，如果当前两个word里所指的字母/末尾字母一样，那解法就和两个指针都前移一格的解法一样！
  2. 如果所指字母不一样：那就在三种等价里面找最小的，在加1！

            curr += wall[i][j] 
            crosses[curr]++
            if crosses[curr] > maxNotCross {
                maxNotCross = crosses[curr]
            }
            
        }
    }
    return m - maxNotCross
}

2487. 从链表中移除节点#

题目：给你一个链表的头节点 head 。移除每个右侧有一个更大数值的节点。返回修改后链表的头节点 head 。

输入：head = [5,2,13,3,8]
输出：[13,8]
解释：需要移除的节点是 5 ，2 和 3 。
- 节点 13 在节点 5 右侧 —— 移除 节点5。
- 节点 13 在节点 2 右侧 —— 移除 节点2。
- 节点 8 在节点 3 右侧。

思路：

把节点从左到右都push进栈，此时栈最顶上就是最右边的节点；定义一个res链表来存储最终的处理后结果，并开始逐个处理栈里的节点：

  • res链表为空的时候，直接把栈顶先插入进去；
  • 如果栈顶节点值 ≥ res的头节点值，把栈顶节点插入到res的头节点位置；
  • 如果小于的话，直接丢弃这个节点——可以理解为，栈顶节点是比res头节点在原链表中更靠左的节点，既然 stTop.Val < resHead.Val，就说明在栈顶节点这个更靠左的节点的右侧出现了更大数值的节点，应丢弃，符合题意！
func removeNodes(head *ListNode) *ListNode {
    st := []*ListNode{} 
    curr := head 
    for curr != nil {
        st = append(st, curr) 
        curr = curr.Next
    } 

    dummy := &ListNode{} 
    for len(st) > 0 {
        node := st[len(st)-1]
        if dummy.Next != nil && node.Val >= dummy.Next.Val {
            next := dummy.Next 
            dummy.Next = node 
            node.Next = next
        } else if dummy.Next == nil {
            dummy.Next = node
        }
        st = st[:len(st)-1] 
    }
    return dummy.Next
}
